# semverguard-types

Shared types for semverguard - configuration schema and report output format.

## Overview

This crate provides:

- **`SemverguardConfig`** - Configuration structure parsed from `semverguard.toml`
- **`RunReport`**, **`PackageReport`**, **`Summary`** - Output schema for machine-readable JSON reports
- **`ListResult`** - Output for the `list` command (preview filtering)
- **`WorkspaceMetadata`**, **`WorkspacePackage`** - Workspace and package metadata types
- **`SemverCheckRequest`**, **`SemverCheckOutput`** - Engine adapter types

## Configuration Schema

```rust
use semverguard_types::SemverguardConfig;

let config: SemverguardConfig = toml::from_str(r#"
    [baseline]
    kind = "git"
    git_rev = "origin/main"

    [scope]
    mode = "changed"
"#)?;
```

## Report Schema

```rust
use semverguard_types::RunReport;

// Reports are generated by SemverguardRunner
let json = serde_json::to_string_pretty(&report)?;
```

## Key Types

| Type | Description |
|------|-------------|
| `SemverguardConfig` | Top-level configuration |
| `BaselineConfig` | Git rev or crates-io version baseline |
| `ScopeConfig` | Filtering mode and include/exclude patterns |
| `FeaturesConfig` | Feature flags for cargo-semver-checks |
| `RunReport` | Top-level output report |
| `PackageReport` | Per-package check result |
| `PackageStatus` | Passed / Failed / Skipped |
| `RequiredBump` | Major / Minor / Patch / Unknown |

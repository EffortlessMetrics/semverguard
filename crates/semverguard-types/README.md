# semverguard-types

Shared types for semverguard - configuration schema and report output format.

## Overview

This crate provides:

- **`Config`** - Configuration structure parsed from `semverguard.toml`
- **`Report`** - Output schema for machine-readable JSON reports
- **`Workspace`** / **`Package`** - Workspace and package metadata types

## Configuration Schema

```rust
use semverguard_types::Config;

let config: Config = toml::from_str(r#"
    [baseline]
    kind = "git"
    rev = "origin/main"

    [scope]
    mode = "changed"
"#)?;
```

## Report Schema

```rust
use semverguard_types::Report;

// Reports are generated by SemverguardRunner
let json = serde_json::to_string_pretty(&report)?;
```
